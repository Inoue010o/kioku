# あそびば図鑑

卒業制作として作った、ゲーム紹介サイトです。ゲームの紹介に加えて、ゲームのアイディアや自作ゲームも載せています。

- 制作者:井上大河
- 制作期間:【ここに記入(例:2026年4月〜10月)】
- 公開URL:【GitHub Pagesを設定したあとにURLを記入】

## 主な機能
- ジャンル絞り込み、検索、並べ替え、機種での絞り込み(22本掲載)
- お気に入り・遊んだ・メモ(ブラウザに保存)
- ゲームの比較表、今日の1本、診断クイズ
- ドット絵風カードと、ドット絵背景6種(赤れんがは古いレトロ表示)
- ライト/ダーク切り替え、効果音、「動きを減らす」設定への対応

## 使い方
`index.html` をブラウザで開くだけで動きます。外部のライブラリや、ビルド作業は不要です。

## 使っている技術
HTML / CSS / JavaScript(フレームワークなし。1ファイル)
